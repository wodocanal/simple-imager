# SD Архиватор

Небольшое нативное macOS-приложение для создания сжатых образов SD-карт и их восстановления.

## Что уже умеет

- показывает только целые внешние физические диски;
- создает потоковый образ `.sdimg.zst` без промежуточного `.img`;
- в компактном режиме исключает свободные кластеры FAT32 и exFAT, не изменяя исходную карту;
- сохраняет манифест и SHA-256 рядом с образом;
- проверяет архив до начала восстановления;
- запрещает запись на внутренний диск и на карту меньшего размера;
- по желанию сверяет всю карту после записи.

Компактный режим уменьшает файл архива, но пока не уменьшает таблицу разделов. Для восстановления нужна карта не меньше исходной.

## Запуск

Требования: macOS 13+, Swift 6 и `zstd` (`brew install zstd`).

```bash
zsh scripts/build-app.sh
open ".build/SD Архиватор.app"
```

Скрипт собирает обычный macOS `.app` и подписывает его локальной ad-hoc подписью. `Package.swift` также можно открыть в Xcode и запускать оттуда.

Для чтения и записи `/dev/rdiskN` macOS показывает стандартный запрос пароля администратора.

## Формат образа

Для `card.sdimg.zst` приложение создает `card.sdimg.zst.json`. Манифест содержит исходный размер носителя, режим создания, обработанные файловые системы и SHA-256 распакованного образа.
