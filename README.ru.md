# Simple Imager

[English version](README.md)

Небольшое нативное macOS-приложение для создания, уменьшения, сжатия, записи и проверки образов внешних накопителей.

## Возможности

- показывает только целые внешние физические диски;
- идентифицирует выбранный носитель по текущему IORegistry ID, пути IORegistry, серийному номеру при его наличии, модели и размеру;
- создаёт образы IMG, RAW и DD;
- записывает образ из локального файла, прямого HTTP/HTTPS-URL или другого внешнего носителя;
- клонирует один внешний носитель напрямую на другой;
- поддерживает ZSTD, GZIP, XZ, BZIP2, LZ4, ZIP и 7Z;
- определяет сжатие по сигнатуре файла, а не только по расширению;
- умеет физически уменьшать последний основной раздел ext2/3/4 в MBR-образе без Docker;
- может добавить одноразовый systemd-сервис для расширения rootfs при первой загрузке;
- не создаёт дополнительный JSON или другой sidecar-файл;
- полностью сверяет целевой носитель после записи и позволяет пропустить уже начавшуюся проверку;
- умеет автоматически извлекать носитель после считывания или записи;
- предупреждает при закрытии во время операции и дожидается безопасной отмены;
- поддерживает английский и русский интерфейс, по умолчанию выбран английский.

## Работа с образом

При создании образа Simple Imager сначала полностью копирует исходный носитель во временный RAW-файл. Затем приложение при необходимости уменьшает поддерживаемый ext-раздел и сжимает результат. Исходный носитель открывается только для чтения и после начального копирования больше не используется.

При записи файла образ ровно один раз распаковывается в приватный временный RAW-файл, одновременно вычисляется SHA-256. Этот же RAW записывается на целевой носитель, после чего носитель читается обратно и сверяется с сохранённым хэшем. Образ по URL полностью скачивается и проверяется до появления подтверждения очистки целевого диска.

Остановка во время записи требует дополнительного подтверждения. Если запись не успела завершиться, Simple Imager инвалидирует начало частично записанного носителя, чтобы macOS не смонтировала незавершённую файловую систему.

## Уменьшение ext

Опция «Уменьшить образ» использует встроенные `e2fsprogs`: проверяет и уменьшает последний основной раздел ext2/3/4, обрабатывает свободные блоки, обновляет MBR и обрезает образ. Такой образ можно записать на меньший носитель, если он вмещает новый логический размер.

Настройка расширения ext при первой загрузке добавляет в совместимый Linux-образ одноразовый systemd-сервис. Он расширяет последний раздел и ext-файловую систему, после чего удаляет себя. Функция рассчитана прежде всего на Raspberry Pi OS и Ubuntu. GPT, расширенные и логические разделы, LVM, шифрование и другие файловые системы пока не уменьшаются.

## Совместимость

Текущая версия поддерживает Mac с Apple silicon и macOS 13 или новее. Intel Mac не поддерживается. Приложение и встроенный runtime собираются только для arm64.

Экран первого запуска проверяет архитектуру, системные компоненты macOS, подпись приложения и SHA-256 встроенных утилит и библиотек. `zstd`, `xz`, `lz4`, `7zz` и необходимые компоненты `e2fsprogs` находятся внутри `.app`. Пользователю не нужны Homebrew, Docker, PiShrink или отдельные кодеки.

Для прямого доступа к `/dev/rdiskN` macOS показывает стандартный запрос пароля администратора. При ошибке Operation not permitted включите для Simple Imager «Полный доступ к диску» и перезапустите приложение.

## Сборка и запуск

Для сборки нужны macOS 13+, Swift 6, Apple silicon и Homebrew-пакеты, из которых формируется автономный runtime:

```bash
brew install zstd xz lz4 sevenzip e2fsprogs gettext
zsh scripts/build-app.sh
open ".build/Simple Imager.app"
```

Скрипт создаёт оптимизированный arm64 `.app`, переносит библиотеки Homebrew в `Contents/Frameworks`, создаёт `RuntimeManifest.plist` и подписывает каждый Mach-O. По умолчанию используется ad-hoc подпись.

Для дистрибутивной сборки укажите сертификат Developer ID:

```bash
CODE_SIGN_IDENTITY="Developer ID Application: Example (TEAMID)" zsh scripts/build-app.sh
```

Для notarization во время сборки настройте профиль `notarytool` в Keychain:

```bash
CODE_SIGN_IDENTITY="Developer ID Application: Example (TEAMID)" \
NOTARYTOOL_PROFILE="simple-imager-notary" \
zsh scripts/build-app.sh
```

## Форматы образов

Базовые расширения: `.img`, `.raw`, `.dd`. Сжатие добавляет второе расширение, например `.img.zst`, `.raw.gz`, `.dd.xz`, `.img.bz2`, `.img.lz4`, `.img.zip` или `.img.7z`.

IMG, RAW и DD содержат один и тот же поблочный образ и отличаются только для совместимости. ZIP и 7Z должны содержать ровно один файл образа. ISO, DMG, BIN и форматы виртуальных машин не поддерживаются.

## Иконка приложения

Редактируемый исходник находится в `Resources/AppIcon.svg`, готовая macOS-иконка — в `Resources/AppIcon.icns`.

```bash
zsh scripts/build-icon.sh "/путь/к/новой-иконке.svg"
zsh scripts/build-app.sh
ditto ".build/Simple Imager.app" "/Applications/Simple Imager.app"
```
